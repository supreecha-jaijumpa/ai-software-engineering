# 8.5 Capstone Acceptance & the Definition of Mastery

- The capstone is successful when ten criteria hold. The first five concern direction: the workflow can start from a written requirement; scope and acceptance criteria are explicit; the codebase is explored before implementation; a traceable plan is reviewed before high-impact changes; implementation follows project conventions.
- The next three concern proof: relevant tests and quality checks run successfully; failures lead to evidence-based correction or escalation; the final output includes changed files, test evidence, risks, and known limitations.
- The last two concern honesty and measurement: the workflow does not claim success without verification; and cost, time, quality, and human intervention can be evaluated.
- Each criterion is judged on evidence recorded during the run — task state history, the approved plan, verification reports, the execution log, the metrics — not on a description of what the workflow is supposed to do.
- Mastery, in the roadmap's definition, is being able to: explain how context, instructions, tools, skills, agents, and verification work together; design a lean Claude Code project structure; build reusable skills and bounded agent roles; and choose single-agent, subagent, or multi-agent execution based on task dependencies.
- And further: create reliable implementation and verification loops; preserve state and recover from interruptions; verify output using tests and independent evidence; protect the repository and external systems with appropriate permissions; measure quality, rework, latency, and cost; improve workflows based on observed failures.
- The final test is teaching: explain the trade-offs of your system to another engineer well enough that they could operate and change it.
- The final principle: do not aim to become an engineer who asks AI to write code faster. Aim to become an engineer who designs reliable systems in which AI can help deliver software correctly, safely, and repeatedly. The engineer owns the outcome.
