# 7.4 Delegation, Model Selection & Deterministic Scripts

- Three decisions change the cost of a task by large factors: whether to delegate it, which model runs it, and whether a model should be doing it at all.
- Subagent context isolation keeps a large exploration out of the main window — the main context pays only for the summary. The exploration itself still costs tokens, plus the overhead of the subagent starting from nothing.
- Delegate only when the task benefits from independent context or parallel work. For a lookup that takes a few tool calls, delegation costs more than it saves.
- Avoid having multiple agents repeat the same exploration. Prepare shared findings once — a feature map, a brief — and hand them to each agent.
- Summaries and handoff artifacts are the currency between contexts: concise, structured, and containing references, so that the receiver does not need to redo the work in order to trust it.
- Model selection or routing, where supported: a smaller, faster model for simple, well-specified work such as searches or mechanical edits; the most capable model for design, ambiguous problems, and review. Check what your tool currently offers.
- A cheaper model that needs two extra correction rounds is not cheaper. Judge the choice by verified outcomes on your own tasks.
- Use scripts for deterministic work — formatting, searching, running tests, generating boilerplate, collecting metrics. A script costs no tokens to execute, gives the same result every time, and returns only its output to the context.
